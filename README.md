# Gabarito Bottons De Coração

Ferramenta gratuita para criação, ajuste e impressão de artes para bottons em formato de coração.

Desenvolvida para facilitar a preparação de artes, organização de cópias e impressão de folhas, com suporte a corte em máquinas Silhouette ou corte manual.

**Status:** Beta · Versão 0.11

## ✨ Funcionalidades

- **Dois modos de corte:** preparação para Silhouette ou corte manual com tesoura.
- **Importação de imagens:** PNG, JPG, WEBP, SVG e PDF.
- **Ajuste de arte:** redimensionamento, rotação, posicionamento e espelhamento.
- **Encaixe inteligente:** ferramentas para preencher a sangria, centralizar e respeitar a área segura.
- **Pré-visualização:** visualização das guias de corte e áreas de impressão.
- **Organização de peças:** distribuição e gerenciamento de múltiplas cópias nas folhas.
- **Exportação:** geração de arquivos PNG, JPEG e PDF.
- **Alta resolução:** opções de exportação de 300 a 600 DPI.
- **Impressão:** preparação de folhas com marcas de registro para Silhouette ou linhas de corte para tesoura.
- **Interface adaptável:** temas claro e escuro.

## 📐 Compatibilidade

O gabarito foi desenvolvido para atender ao padrão de bottons em formato de coração utilizado em prensas manuais.

- **Prensas compatíveis:** Mecolour e modelos importados.
- **Série:** DC 108.
- **Formato da matriz:** Coração.
- **Dimensões da matriz:** 57 × 53 mm.

## 🖥️ Como utilizar

1. Acesse a aplicação pelo GitHub Pages.
2. Escolha entre **Corte pela Silhouette** ou **Corte manual**.
3. Importe sua arte ou cole uma imagem usando `Ctrl + V`.
4. Ajuste o tamanho, a posição e a rotação.
5. Utilize as linhas de referência para posicionar corretamente os elementos.
6. Envie a arte para a folha de impressão.
7. Organize as cópias e exporte o resultado.

## 🎨 Arquivos e gabaritos

Além da ferramenta online, o projeto disponibiliza os arquivos de gabarito utilizados no fluxo de trabalho, permitindo personalização e edição em diferentes programas.

**Formatos disponíveis no app:**
- PSD — Adobe Photoshop
- AI — Adobe Illustrator
- Affinity — Affinity Designer
- CDR — CorelDRAW

## 📏 Guias do gabarito

O editor utiliza linhas de referência para auxiliar na preparação da arte:

| Guia | Significado |
|---|---|
| Vermelha | Sangria |
| Preta | Linha de corte |
| Laranja | Área de risco |
| Amarela | Área segura |
| Verde | Área visível |
